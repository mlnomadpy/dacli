# Use one mutually exclusive evidenced-outcome criterion for evidence review anchors
## Chose
Use one mutually exclusive evidenced-outcome criterion for evidence review anchors
## Rejected
Add a separate optional honest-empty checkbox or have orchestration auto-close anchors
## Because
A single exactly-one criterion expresses the contract without requiring reviewers to check contradictory outcomes, while preserving reviewer-owned evidence and lifecycle actions.
