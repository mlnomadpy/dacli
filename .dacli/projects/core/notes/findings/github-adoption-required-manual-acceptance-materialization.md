# GitHub adoption required manual acceptance materialization
Issues #717 and #718 were adopted with their detailed Acceptance criteria prose but zero executable ## Acceptance boxes. Root manually copied those criteria into checkboxes and estimated the tasks. This is additional evidence that inbound adoption should preserve checkable issue criteria or provide an audited task-edit surface.
