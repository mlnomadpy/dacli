# runtime-process-safety
Separate runtime invocation from provider-neutral result records. Probe declared capabilities; do not infer read-only, model selection, usage, or auth from a binary existing. Treat worktrees as isolation, not permissions. Preserve process identity across PID reuse, kill whole groups, complete run records atomically, and make failed startup recoverable. Never silently load undeclared user configuration or call a cooperative runtime strict read-only.
