# github-delivery
GitHub issues and PRs are the human collaboration surface; dacli is the execution/evidence record. Check semantic duplicates, preview broad mirror mutations, use marker-idempotent recovery, and verify remote state after interrupted output. Push only the task branch, wait for all required checks, merge through the governed path when possible, and close the issue only after trunk contains the work.
