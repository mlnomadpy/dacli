# go-system-design
Preserve the dependency direction shared/entities/features/app and feature-slice isolation. Treat markdown state, locks, atomic writes, process records, and exit codes as protocols. Fail closed at authorization, landing, and evidence boundaries. Measure mature-workspace paths before optimizing; prefer one indexed snapshot per command over repeated full scans. Keep behavior changes mutation-tested and compatible with Go 1.22.
