01 · responsibilities

Agents make judgments. dacli keeps the process true.

Humans set direction and authority. An orchestrator agent plans and evaluates. dacli enforces state, policy, cost, and lifecycle. Coding-agent CLIs implement and review. GitHub supplies CI and landing evidence.

direction→ plan + route→ execute + review→ verify + land→ learn↺

Each cycle is bounded by recorded policy: no evidence-backed work → idle; budget spent → cooldown; repeated no-progress cycles → halt. Humans retain the kill switch, exception authority, and release policy.

02 · what you get

Durable context and critical-path work

Each agent receives a scoped brief with the goal, constraints, decisions, dependencies, and sibling findings it needs—without paying for the whole repository.

Replaceable coding CLIs

Route by capability, cost, context, and health across Codex, Claude Code, Gemini CLI, Copilot CLI, or a generic executable—without changing the workflow.

Bounded autonomy

Claims, grants, token windows, trust gates, stop conditions, and recovery journals turn unattended execution into explicit, inspectable transactions.

Verified GitHub landing

Issues organize visible work; isolated branches become reviewed PRs; CI and merge state are observed before dacli records completion.

Evidence that compounds

Every run freezes its brief, invocation, transcript, outcome, cost, and attribution. Reviews and retros feed the next cycle instead of disappearing with the agent session.
