01 · the loop

Set the direction. It runs the sprint.

One command runs the whole process — review, plan, implement, test, land, retro — then around again, with no human in the loop.

review→ plan→ implement→ test→ land green PRs↺

A pure governor gates every cycle: empty backlog → it idles (never invents busywork); budget spent → it sleeps; nothing lands for N cycles → it halts. It knows when to stop.

02 · what you get

Context on tap

Each subagent starts blind. dacli context <task> --budget N hands it one self-contained, token-budgeted brief — task, goal, constraints, prior decisions, siblings' findings — instead of the whole repo.

A real agent fleet

spawn launches child coding-agent CLIs in isolated worktrees; --claim reserves files; wait, accept, ship tie off a whole wave.

Governed, not runaway

A trust-floor on every brief, a taint gate against injected sources, calibrated token budgets, and a loop that halts on thrash. Safe to leave running.

Mission control

dacli dashboard shows the live swarm, burn-rate, the task DAG, and per-agent state (thinking · acting · waiting · stalled) — one binary, zero CDN.

GitHub, both ways · everything recorded

Tasks ↔ issues, findings → issues, PRs that self-land on green CI. Every run freezes its brief, invocation, transcript, and outcome; every commit is attributed to the agent and role that authored it.
